# EDR 使用手册

本文说明平台部署、数据库与依赖组件配置、启动与日常运维。默认以 **Windows Server / 本机** 为例。

---

## 1. 组件一览

| 组件 | 是否必须 | 作用 |
|------|----------|------|
| Python 3.11+ / 本仓库 `edr_server.py` | 是 | EDR 管理台与 API（默认 `:8100`） |
| SQLite（`reports/` 等） | 是 | 默认本地库；无 MySQL 时仍可运行 |
| **MySQL 8 / MariaDB** | 推荐（生产） | 主机台账、平台配置、IOC/分析等管理数据 |
| **Redis** | 可选 | IOC 查询缓存等加速 |
| **Elasticsearch** | 可选 | 检测语料 / 检索增强（见 `hj_stack`） |
| Agent（`forensic-agent`） | 业务需要 | 终端采集与上报 |

未启用 MySQL 时，服务会自动回退 SQLite，功能可用，但不适合多实例或大规模生产。

## 2. 数据库部署（MySQL）

### 2.1 安装

任选其一即可：

- **phpStudy / 宝塔 / XAMPP** 等集成环境开启 MySQL 8
- 官方 [MySQL Community Server](https://dev.mysql.com/downloads/mysql/) 或 MariaDB

确认服务已启动，端口默认 `3306`，字符集建议 `utf8mb4`。

Python 依赖：

```powershell
pip install pymysql
```

### 2.2 创建库与账号（推荐独立账号）

用管理员登录 MySQL 后执行（密码请改成强密码）：

```sql
CREATE DATABASE IF NOT EXISTS forensic_platform
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'forensic_app'@'localhost' IDENTIFIED BY '请换成强密码';
CREATE USER IF NOT EXISTS 'forensic_app'@'127.0.0.1' IDENTIFIED BY '请换成强密码';

GRANT ALL PRIVILEGES ON forensic_platform.* TO 'forensic_app'@'localhost';
GRANT ALL PRIVILEGES ON forensic_platform.* TO 'forensic_app'@'127.0.0.1';
FLUSH PRIVILEGES;
```

说明：

- 若应用与 MySQL 同机，用 `localhost` / `127.0.0.1` 即可。
- 若 MySQL 在另一台机器，把主机名改成 `'forensic_app'@'%'` 或具体网段，并在防火墙放行 `3306`（仅内网）。
- **不要用 root 跑业务**；不要把真实密码写进 Git。

> 程序启动时也会尝试 `CREATE DATABASE IF NOT EXISTS` 并自动建表；前提是配置账号对目标库有建库/建表权限。权限不足时请按上文手工建库授权。

### 2.3 写入平台配置

```powershell
cd config
copy db_config.example.json db_config.json
```

编辑 `config/db_config.json`：

```json
{
  "enabled": true,
  "host": "127.0.0.1",
  "port": 3306,
  "user": "forensic_app",
  "password": "与上面 CREATE USER 一致的强密码",
  "database": "forensic_platform",
  "charset": "utf8mb4",
  "pool_size": 20,
  "redis": {
    "enabled": false,
    "host": "127.0.0.1",
    "port": 6379,
    "password": "",
    "db": 0,
    "key_prefix": "edr:"
  },
  "elasticsearch": {
    "enabled": false,
    "hosts": ["https://127.0.0.1:9200"],
    "user": "elastic",
    "password": "",
    "verify_certs": false
  }
}
```

要点：

- `"enabled": true` 才会连 MySQL；`false` 则全程 SQLite。
- `db_config.json` 已在 `.gitignore` 中，**勿提交仓库**。
- 也可用环境变量覆盖：`FORENSIC_MYSQL_ENABLED`、`FORENSIC_MYSQL_HOST`、`FORENSIC_MYSQL_PORT`、`FORENSIC_MYSQL_USER`、`FORENSIC_MYSQL_PASSWORD`、`FORENSIC_MYSQL_DATABASE`。

### 2.4 验证

1. 启动 EDR：`python edr_server.py --port 8100`
2. 控制台应出现类似：`[mysql] connected 127.0.0.1:3306/forensic_platform ...`
3. 若出现 `setup failed, fallback sqlite`，根据报错检查：服务是否启动、账号密码、库名、防火墙、是否安装 `pymysql`。

表结构由程序自动维护（`hosts`、用户、审计、平台密钥等），一般**无需手工导入 SQL 脚本**。

## 3. Redis（可选）

用于 IOC 等查询缓存，非必须。

1. 安装并启动 Redis（Windows 可用 Memurai / 官方发行版 / WSL）。
2. 在 `db_config.json` 的 `redis` 段：

```json
"redis": {
  "enabled": true,
  "host": "127.0.0.1",
  "port": 6379,
  "password": "",
  "db": 0,
  "key_prefix": "edr:"
}
```

3. 环境变量可选：`FORENSIC_REDIS_ENABLED`、`FORENSIC_REDIS_HOST`、`FORENSIC_REDIS_PORT`、`FORENSIC_REDIS_PASSWORD` 等。
4. Redis 不可用时平台仍可运行，仅缓存加速失效。

---

## 4. Elasticsearch（可选）

用于检测语料 / 检索增强，非 EDR 基础告警所必需。

1. 复制并编辑：

```powershell
copy config\hj_stack.example.json config\hj_stack.json
copy config\stack_paths.example.json config\stack_paths.json
```

2. 填写本机 ES / Kibana 安装路径与 URL；在 `db_config.json` 中按需打开 `elasticsearch.enabled`。
3. 可用脚本探测/启动（路径与本机一致时）：

```powershell
.\scripts\ensure-stack.ps1
.\scripts\start_hj_elasticsearch.ps1
python scripts\setup_elasticsearch_edr.py
```

## 5. 首次启动与账号

```powershell
# 其它配置（至少一次）
cd config
copy ai_config.example.json ai_config.json
copy platform_settings.example.json platform_settings.json

# 启动
cd ..
python edr_server.py --port 8100
# 或
.\start-edr.ps1
```

浏览器打开：`http://127.0.0.1:8100`

- 首次启动自动创建 `admin`，临时密码打印在服务窗口；首次登录须改密。
- 可预先设置：`EDR_BOOTSTRAP_ADMIN_PASSWORD`
- 忘记密码：`python edr_server.py --reset-admin`

## 6. Agent 与管理台

- **下载安装包**：登录管理台 → 部署相关入口；包内嵌平台地址与接入密钥。
- **管理台前端构建**（改 UI 后）：

```powershell
cd agent_admin
npm install
npm run build
```

产物由 `edr_server.py` 托管。

- **Agent 编译**（需要时）：`python scripts\build_agent.py`

更多见 `agent/README.md`、`agent_admin/README.md`。

## 7. 公网暴露（可选）

不要把 `:8100` 直接暴露到公网。参考 `deploy/README.md`，用 Nginx / Caddy 做 HTTPS 与反向代理，应用只监听内网。

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 启动一直 SQLite / `MySQL disabled` | `db_config.json` 里 `enabled` 是否为 `true`，文件是否在 `config/` |
| `Access denied` | 用户、密码、主机（`localhost` vs `%`）是否匹配 |
| `Can't connect` | MySQL 服务、端口、防火墙 |
| `pymysql not installed` | `pip install pymysql` |
| 表缺失 | 确认账号有 `CREATE`；重启服务触发 `ensure_database_and_schema` |
| 改配置不生效 | 改的是 `config/db_config.json` 后需重启 `edr_server` |

---

## 9. 安全注意

- `db_config.json`、`ai_config.json`、`platform_secret.key` 含密钥，禁止入库。
- 生产使用独立数据库账号与强密码；限制 MySQL / Redis 仅内网可达。
- 定期备份 MySQL（`forensic_platform`）以及 `reports/`、`config/`（不含明文密钥的流程按单位规范执行）。
