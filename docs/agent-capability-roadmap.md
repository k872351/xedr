# Agent 能力增强路线（相对 OpenEDR / Wazuh / DataProtector）

## P0 优先（代码可推进）

| 编号 | 项 | 现状与方向 |
|---|---|---|
| AG-01～04 | 采集完整性 / 丢失 / 来源 / 健康 | 扩展 `telemetry_metrics`、`component_health_state`、`health_score`；管理端已有采集质量面板 |
| AG-16～19 | 持久化一致性 / 恢复 / 身份 / 本地权限 | 对照 OpenEDR 组件与现有 tombstone / 凭据哈希 |
| AG-40～43 | 凭据存储 / 策略验签 / HTTPS / 本地权限 | 策略 Ed25519、HTTPS 中间件已部分落地，继续加固 |
| AG-59～60 | 覆盖安装身份 / 失败恢复 | 安装脚本与 tombstone 联调验收 |

## P1 / 验收类

AG-05～15 字段一致性；AG-20～28 生命周期与资源；AG-30～39 健康指标展示；AG-44～48 安全；AG-49～58 跨平台；AG-61～68 安装与稳定性——以合成数据与授权终端验收为主。

## 采集原则

最小必要：不采集用户隐私、凭据、私人通信等敏感内容；缺失字段区分「不适用 / 未知 / 失败」。
